# demo_coding_agent

A generic coding-assistant [GAP](https://github.com/gitagent-protocol) agent that can do small engineering tasks - read/write/edit code, run shell commands, investigate and fix bugs.

## Files

- `agent.yaml` - GAP manifest
- `SOUL.md` - system prompt / persona
- `project/` - core utility functions and tests
- `docs/` - onboarding and process notes
